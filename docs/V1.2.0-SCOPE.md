# v1.2.0 听懂这一页：已确认范围

2026-10-27，需求经 grilling 分轮确认，用户明确授权开发。

- 一次上传或粘贴一张 PNG/JPEG/WebP 课件，一课多图；先本机保存，不自动调用 AI。默认从添加时刻关联到下一张，可修改起止时间。使用课堂累计录音时钟，暂停不推进。
- 所选范围内图片共同参与，每次最多四张，超过须明确选择或缩小范围，不自动遗漏。
- “刚才没听懂”：最近 30 秒、2 分钟、一个意群。点击冻结范围、当时可用原文及图片，确认和排队不改变材料。迟到转写提示缺失，补齐后重新解释产生新记录；完全无文字时提示等待。
- 以片段为时间粒度，跨边界保留整段，显示请求范围和实际范围；手动原文时间明确为估计。意群只用当时选中内容，不暗中混入其他摘要或旧答案。
- 中文直白解释、两三步原因、具体例子；英文关键术语保留。区分老师材料与补充知识；图文冲突、看不清或材料不足必须说明。答案可回看每张图及原文快照，修改不改写历史依据。
- Codex CLI 和既有 OpenAI 兼容 Chat Completions 接口都适配多图。未知图片能力可明确尝试；明确不支持时提示换模型或主动仅用文字。一般网络/额度/参数错误不伪装为不支持图片。
- 图片首次发送前展示接入、地址、模型、图片、完整原文范围及问题。同课堂/同图/同接入配置可记住同意；更换图片或接入重新确认。本地 Codex 仍向其账号服务发送材料。
- 加载期间禁止普通接入更换，保留强制更换。已发请求不保证撤回/免计费；强制后需要重新确认目的地，原材料保留，旧请求结果不覆盖新结果。
- 本地保存图片及依据，刷新/重启可回看。JSON/Markdown 导出提供图片相对路径和依据，明确不含图片本体；课堂目录一并备份。本版不新增媒体 ZIP 导出。

## 验收与权限

使用隔离数据和合成供需图完成“上传课件→关联讲解→解释均衡变化→回看图片和原文”，包含双图、四图上限、积压、失败、模型不支持、接入切换、恢复和导出。

真实 Codex 合成图文请求最多三次，由主代理统一执行；不得读取/导出账号凭据，不使用真实课堂资料。API 使用模拟服务，不调用收费 API，不开启真实麦克风。真实看图未通过则明确标记验收未完成。

升级保留现有课堂数据、配置、模型和运行环境；开发在独立分支。发布前提交准确 commit、版本及 tag 给用户确认，未确认不 push/tag/Release。
