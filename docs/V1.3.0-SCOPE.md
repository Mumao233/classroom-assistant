- 此文保留已批准的设计要求；实际实现和验收以 VALIDATION 为准。自动化、实际 HTTP/UI 和静态阅读页检查已完成，直接 file:// 双击受工具策略限制仍待人工复验。发布仍另行确认。

## 方案取舍

1. 推荐：原有课堂三栏 + 独立“本课复习”视图；结构化卡片与版本笔记；带离线阅读页的 ZIP 课堂包。能完整验证来源回跳、离线回看和恢复。
2. 仅增强 Markdown/JSON：开发较少，但图片、原音和离线阅读依赖外部文件，不能完整满足验收。
3. 云同步/Anki/复杂手写批注：范围与依赖明显增加，本版不采用。

## 1. 标记与来源

- 在每段原文、每张课件旁提供“重点”“没懂”，可同时存在，可撤销，允许附简短备注。
- 本版按整段原文或整张课件标记，不新增图上绘画、OCR 或跨段划词工具。
- 标记保存 classroom ID、材料 ID、原文版本/图片版本和哈希、课堂时间及原始快照。
- 修改原文或旋转/改时间/移除课件后，标记保留，显示“依据已变化，待核对”，不悄悄迁移到新材料；可明确重新关联。
- “没懂”在生成解释后仍保留，只有用户点“已理解”才转为已解决。
- 标记只在本机保存，不触发 AI 请求。切课、刷新、重启后仍归属原课堂。

## 2. 复习入口与生成范围

- 保留现有上课三栏；新增“本课复习”入口，提供标记、卡片、笔记和课堂包导出/恢复。
- 默认整理本节课已完成的现有材料，优先安排有标记的内容；可选择“只整理标记”或明确时间范围。
- 点击生成时冻结整次材料和标记；显示覆盖时间、材料数、未完成转写/缺失图片、目标服务商/地址/模型、预计批次数。
- 仍在转写或老师继续讲，不把后来新增内容偷偷加入本次生成；范围以已确认快照为准。
- 无材料时不生成，不把课程预设/通用知识当作老师讲解。只含课件也允许整理，但必须注明无原文、无原音定位。
- 沿用应用配置的字符预算和单次最多四图，预算纳入指令/JSON 包装并为输出留余量；这不是已经验证的服务商 token 容量。长课堂按完整原文段落和图片版本在本机确定性分批，不静默截断或漏图。单段不能容纳时明确阻止并说明；服务商仍拒绝输入过长时停止并提示，不自动裁剪重试。
- 用户确认一次完整计划后，按显示的批次顺序执行；失败、结果未知、接入变化或服务重启后停止后续批次，手动核对/继续，不能静默补发。
- 汇总笔记所需的额外模型请求计入预览的计划。超过可安全汇总范围时按主题分节并显示覆盖信息，不暗中丢弃前半节课。

## 3. 卡片

- 四类：概念、推导、例题、易错点。用户可选择类别；按实际材料生成，不强凑每类数量。
- 每张卡片包含标题、正面问题、背面解释/步骤、来源范围、关联课件、原音入口和缺失提示。
- 支持先看问题、点击揭晓答案的简单刷卡方式；本版不加入间隔复习算法、背诵日程或跨课知识库。
- 所有整理结果均标为 AI 整理；教师材料单独显示原文摘录/课件依据，用户补充单独保存。
- 课堂没有给出的推导、公式、参数或题目条件，显示“课堂记录不足/缺少步骤”，不补造完整证明或老师答案。
- 通用解释与额外例子只能放在明确标注的“AI 补充”区域，不能填进“老师讲解”。
- 微观经济学预设默认勾选“英文答题表述”，其他课程可手动开启；表述为 AI 建议，附中文意思，不冒充老师原话。
- 相同范围、材料版本、生成选项与目的地的重复点击/刷新恢复返回同一生成任务；相同任务不重复提交产物。同一来源可生成多个不同知识点的卡片。
- 去重使用完整来源快照、卡型/语言/参数、提示词/结构/分批规则版本和目的地的指纹，在同一课堂锁内核对；不能只依赖浏览器请求 ID。
- 同类型、语言、来源和规范化题面/答案指纹完全相同的卡片去重；相近但不完全相同的卡片保留供核对，不承诺跨表述语义去重。
- 原文更新后显示“需要更新”；重新生成创建新版本，与旧版并列查看。用户编辑正文和个人备注单独留存，不自动覆盖。
- “查看依据”首先显示生成时快照；提供跳到当前原文及历史图的入口，明确新旧差异。回听使用课堂 ID + 音频序号 + 实际片段内偏移；不是逐词精确对齐。

## 4. 课后笔记

- 固定结构：知识结构、重点内容、未解决疑问、关联课件；优先展开重点/没懂标记。
- 每个知识条目关联实际来源；保留教师摘录、AI 整理/补充、个人笔记的区分。
- 每次正式 AI 结果另存版本，编辑中的个人版本独立保存。更新只产生候选版本，不自动替换用户选定笔记。
- 用户可对照新旧内容，显式采用新版本或继续编辑原版；不做未经确认的自动合并。
- 当前来源变化时显示待更新；生成后新增课堂材料显示“新增内容尚未纳入”，与旧依据被改动区分。
- 自动保存必须有成功/失败状态；刷新、切课、多标签修改冲突不能静默覆盖用户文字。失败保留输入，并提供恢复入口。

## 5. 生成状态与付费请求保护

- 分开保存生成计划、每批执行尝试和最终卡片/笔记版本，不仅保存一个 done 标志。
- AI 原始输出、通过校验的正式产物、用户编辑稿三份分离；编辑保存核对版本号，过期编辑不能覆盖别的标签页已保存版本。
- 批次逐个调度，实时问答可在批次之间插入；不会一次填满队列阻塞上课流程。
- 状态至少区分待确认、等待、生成中、部分完成、完成、失败、结果未知、取消。
- 每批完整返回且通过结构、长度和来源编号校验、成功落盘后，才形成正式产物；流式草稿永远标为未完成。
- 非法 JSON 或无效引用保留原始结果并提示失败，不额外调用模型自动修复。材料提交覆盖不等于 AI 已理解每个知识点。
- 整体“完成”要求所有计划材料均已处理且最终笔记已校验/保存。缺失材料、处理失败或未完成批次必须列出，不伪装整课成功。
- 每次网络尝试先持久记录，响应丢失先查原任务；跨刷新、重启、双击不自动再次收费。
- 超时保持原文案：“请求超时、无法确定服务商是否已处理”。再次请求需明确确认重复计费风险。
- 来源修改会使尚未发送的批次暂停，允许明确继续旧快照或新建计划；普通续讲不改旧快照。
- 模型不支持图片时明确阻止相关图文批次；用户可明确新建纯文字计划，不能自动换模型或假装看图。
- 本地校验能发现无效引用和结构缺失，不能证明模型理解、事实或数学推理一定正确。

## 6. 导出、离线阅读与恢复

- 保留现有 JSON/Markdown 导出，新增标记、卡片、笔记、来源版本、时间、图片引用及音频定位和可用状态；单独文件不承诺包含媒体。
- 新增 ZIP 课堂包：index.html 离线阅读页、结构化 JSON、Markdown、校验清单和所引用图片/历史图片；录音默认不含，可勾选加入本课现存录音。
- 解压后直接打开 index.html；不依赖 localhost、联网 CDN 或启动后端。来源锚点和媒体使用包内相对路径。
- 包内标注生成时覆盖范围、课堂原文与机器原稿、AI 内容、个人修改、过期/缺失状态和导出时间。
- 没有录音、已删除、文件损坏、手动补充没有原音、未勾选带录音分别显示；不提供看似可用但实际失效的回听按钮。
- 缺图/缺音在导出预检中列出。用户明确选择带缺失说明导出时保留占位和清单；写入失败/空间不足不能产生成功标记的半包。
- UTF-8 保留中文、英文、emoji 与公式源文；离线附带本地公式渲染资源。支持的公式正常显示，渲染失败则明确显示原公式文本，不吞字符、不改写公式。
- 离线阅读只读；如需继续编辑，在应用中恢复课堂包。恢复默认创建独立课堂副本，保留来源 classroom ID；不覆盖现有课堂。
- 来源 S/P/Q/G ID、版本、时间、哈希和音频序号在副本课堂内保留；所有操作使用新的课堂 ID，不跨课引用旧音频。
- 原始证据快照不改写；副本持有受限的“来源课堂到本副本”映射。标记、卡片、图片、音频与快照内旧 classroom ID 只能在当前副本中解析，不能凭旧 ID 访问本机原课堂或其他副本。
- 恢复不导入账号配置/凭据，不激活旧队列、未完成 AI 请求或发送授权，不自动开始转写。
- 课堂包不是整套应用备份：不含模型、运行环境、浏览器待上传图片或尚未同步的页面草稿。导出前提示先保存编辑/处理未上传项。关联课程预设保存只读快照，恢复时不绑定本机碰巧同 ID 的其他预设。
- 恢复请求也有稳定标识；响应丢失先核对已恢复副本，重复同一请求不会生成第二节课堂；用户主动再次导入才建第二份副本。
- 图片/音频先校验，再暂存导入、最后一次性登记新课堂；失败不污染已有数据，损坏的必需元数据不以“部分成功”掩盖。
- 拒绝绝对路径、..、盘符/UNC、符号链接/重解析点、Windows 设备名/ADS、重复路径与大小写冲突、越界文件、ZIP 炸弹和未来不兼容格式；不会执行导入包中的 HTML/JS。阅读页只执行应用自带代码，用户和 AI 内容均按安全文本呈现。
- 离线页和应用均只展示安全文本/受限 Markdown，禁止原始 HTML、危险链接协议和公式中的执行/外链能力；嵌入数据必须安全编码，不能被文字中的 </script> 提前截断。
- 初始包边界：ZIP 与实际展开总量均不超过 2 GiB，最多 10,000 文件；清单 8 MiB、课堂 JSON 64 MiB。图片沿用 10 MiB/24MP，音频沿用现有 PCM WAV 格式与片段上限。
- 导出在磁盘流式构建、验证后下载；浏览器不把整个大包读成 Blob。显示的是基于现存文件的估计，不承诺 ZIP 最终精确大小。
- 导出包是本地文件，不上传云端。
- 本版交付 JSON、Markdown 与 ZIP 离线课堂包，不扩展 PDF、Word、Anki 或云同步。

## 7. 兼容与数据保护

- 为新增复习数据和课堂包增加独立 schema_version；现有 session 字段保持含义，不批量改写旧课堂。
- 旧版缺失的新字段按空集合/旧版本处理；第一次实际保存相关变更时才写入，机器原稿和所有历史版本保留。
- 读取历史课堂与从外部课堂包恢复使用不同校验路径；不能把解压文件直接交给旧 loader 作为信任依据。
- 旧 JSON 可恢复文字和可验证的定位元数据；没有媒体时明确报告，不能从电脑其他目录自动搜图/找录音。
- 删除录音仅处理已登记录音，保留原文、机器原稿、标记、卡片、笔记及来源时间；原音入口即时显示已删除。
- 导出与删除录音并发时固定包快照并校验文件，要么完整完成，要么报错/请求明确缺失导出，不能静默漏音。
- 升级前备份完整课堂目录；恢复验收在隔离目录进行。回退使用升级前程序/数据备份，升级后新内容另存；不要求旧版理解 v1.3.0 复习任务。

## 9. 验收矩阵与完成门槛

1. 合成微观经济学一课：供需图、原文和录音 → 标重点/没懂 → 四类适用卡片和英文表述 → 知识结构笔记 → 卡片回到原文与原音。
2. 原文编辑、旋转/移除图片、改关联时间：旧卡片/笔记快照不变且提示待更新；新版本不覆盖手改内容。
3. 重复点击、不同请求 ID 的同内容、并发标签、响应丢失、输出结构错误、流式中断、超时、磁盘写入失败、后台重启：不重复正式卡片，不误报完成，不静默重复请求。
4. 长课多批：全部材料覆盖/缺失清单、标记优先、失败后已有成果保留，恢复只处理明确批准的未完成批次。
5. ZIP 解压离线打开：图片/历史图、中文英文 emoji、受支持公式、来源锚点、可选原音定位；缺媒体/损坏明确标注，关闭后端仍可读。
6. v1.0/v1.1/v1.2 合成旧结构载入、旧 JSON 恢复、完整包备份恢复到新副本、重复恢复、版本不兼容与损坏包拒绝；原课堂和两个恢复副本并存时，修改/删媒体互不影响。恶意 HTML/链接/公式及 </script> 文本在离线页和恢复后均不能执行。
7. 删除录音前后逐字段比较：文字/卡片/笔记/历史依据保留；恢复含录音备份后可回听。
8. 跨课堂、刷新、重启与编辑冲突；原有实时转写、图文问答、失败队列回归不倒退。
9. Python 全套、Node、Python/JS/PowerShell 静态检查、真实回环 HTTP、真实 Windows 浏览器和离线页面验收。
10. 用合成材料与假 AI/ASR；模拟验证、真实本机 HTTP/UI、静态检查和未验证范围分别报告。真实服务商/麦克风/CUDA/续航未经实测不能宣称通过。
11. 更新版本、README、CHANGELOG、VALIDATION、升级/回退说明；最终 diff 无真实数据/配置/密钥/媒体/测试垃圾。
12. 完成后交付准确提交、测试结果和发布草稿。用户确认发布前不 push、tag 或创建 Release。

## 当前事实与潜在风险的区分

- 开发开始时的基线：没有复习卡片/课后笔记/课堂包导入；导出不包含媒体；音频删除实现不删除文字。
- 需设计并验证的风险：复习来源失效、重复卡片、半成品误标完成、离线链接/公式、导入隔离、并发编辑与导出/删除竞态。
- 未对实际用户课堂作测试，也没有把上述风险说成已复现的现版本 bug。
