# v1.3.0 把课堂带走 Implementation Plan

> **For agentic workers:** Use the available collaboration agents to implement the following bounded tasks. The planner's optional subagent-driven-development/executing-plans companion skills are not installed; native collaboration provides the equivalent execution and review checkpoints. Steps use checkbox syntax for tracking.

**Goal:** Build source-linked review marks, versioned cards/notes, and an offline portable classroom package without losing originals or silently repeating paid calls.
**Architecture:** Add a separate review state under each classroom, retain immutable evidence and independent run/batch/artifact records, and use the existing single AI queue. Portable export/import and the browser review view consume the same public structure.
**Tech Stack:** Python/FastAPI, plain JavaScript, local KaTeX, JSON/ZIP, pytest/Node; synthetic AI/ASR only.

## File ownership and contracts

- Root: review_schema.py, codex_bridge.py, static/review-render.js, static/vendor/katex, schema/bridge/render tests, final acceptance and documentation.
- Backend: review_workflow.py and review support modules, app.py, classroom_features.py lifecycle hooks, Python workflow tests.
- Frontend: static/review.js, app.js, index.html, styles.css, Node review UI tests.
- Portable: portable_package.py, portable_routes.py and support modules, static/portable-reader.js/css, package and import tests.
- Bridge method: generate_review(evidence, options, images, *, cancel_event=None) returns unmodified provider JSON text. validate_review_output(raw,evidence,options) returns validated cards/notes or raises ReviewValidationError.
- Result schema 1: cards have type,title,front,back,supplement,english,english_meaning,source_ids,missing; notes have section,title,body,supplement,source_ids,missing. Every source_id must identify actual frozen input.
- Shared session.review has schema_version,marks,runs,cards,notes,selected_note_id,receipts. Backend owns exact public API; UI/package workers communicate directly on contract updates.
