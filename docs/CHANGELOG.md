# 版本记录

## v1.2.1 · 2026-10-28 · 图文别串课

- 图片支持左右 90 度预览并另存不可变版本；移除课件只影响后续选择。旧答案继续访问原图，分别显示旋转、移除、改时间、改原文提示；缺失或损坏的图片明确不可查看，不以新图替代。
- 保持每图 10 MiB / 2,400 万像素限制，补充实际大小、尺寸和拒绝原因，不自动压缩。上传失败的原图、原课堂、原时间、请求标识保存在浏览器本机；最多 10 张 / 100 MiB，可手动核对重试或按课堂清理，不自动过期或重传。无法存储时明确提示仅当前页保留。
- 修复跨课堂草稿、确认框和迟到回调混入；提问草稿按课堂保存。失败图片恢复可插回原时间，后来的课件不会使恢复失败；人工设置的时间段和历史证据不被改写。
- 提问冻结图文版本；正常续讲不移动引用范围。材料在准备后或排队中修改时，发送前退回确认，可继续原快照或重新取材；已发送请求仍按原快照完成。
- 上传、旋转、准备问题、重试和普通问答采用持久请求标识，丢失响应先核对原任务。发送前先记录状态，刷新、切课、后台重启和通用队列恢复不会静默重发结果未知的请求。超时显示「请求超时、无法确定服务商是否已处理」，主动重试需确认可能重复计费。

旧记录兼容读取，不批量迁移；保留 `data/`、配置、模型和运行环境。回退须使用升级前备份，另存新版完整课堂及图片，旧版不用于重试新版记录。验证范围见 [VALIDATION](VALIDATION.md)，升级回退见 [README](../README.md)。本版本发布仍需单独确认。

## v1.2.0 · 2026-10-27 · 听懂这一页

- 单张 PNG/JPEG/WebP 上传或粘贴，本机保存并关联课堂时间；一节课可有多张课件，支持修改标题和起止范围。默认从添加时刻持续到下一张。
- 「刚才没听懂」支持最近 30 秒、2 分钟或一个意群；也可结合课件提问。点击时固定可见原文版本、意群成员与图片关联，后到转写或改字不混入原请求。每次最多四图，超过必须明确选择，不静默漏图。
- Codex CLI 与 OpenAI 兼容 Chat Completions 接口可发送图片。发送前显示目的地、模型、图片和原文范围；能力未知明确说明，确认不支持时不假装看懂，不自动降级重发。
- 答案保留本次依据，支持回看图片、原文快照、范围与完整性提示。重试沿用原快照；主动用新材料解释产生新记录。JSON/Markdown 导出图片路径和依据，不包含图片本体。
- 加载时阻止普通 AI 接入切换，允许强制更换；强制后旧图文请求失效，保留材料、重新确认目的地再发，旧返回不能覆盖新结果。取消不能保证撤回已送达服务商的请求或用量。
- 回归修复点击期间的材料漂移、意群后续补完导致旧快照丢失不完整提示、类似来源编号的普通文字被误认成引用，以及磁盘保存失败造成取消不完整/AI 工作线程退出。完成但尚未保存的答案保留在内存并暂停提示，显式恢复时保存，不自动重发。

新增 Pillow 图片依赖。图片/课堂数据继续保存在本机，升级无需批量迁移旧记录；回退使用升级前备份，新版课堂另存。验证结果与限制见 [VALIDATION](VALIDATION.md)，操作和升级步骤见 [README](../README.md)。

## v1.1.1 · 2026-10-24

- 统一手动原文／原文编辑（12,000）、提问（4,000）和课程大纲（12,000）的输入上限，由服务端提供给网页；按 Unicode 码点计数，空白计入，不扩大 AI 上下文。
- 超限时具体提示字段、上限与当前长度，保留页面输入；取消会按 UTF-16 计数并截断粘贴的原生 maxlength。直接调用接口仍校验，纯空白原文和问题不再被接受。
- 手动原文和问题发送等待期间继续输入的新草稿，不再被上一笔成功响应清空。
- 新课堂保存递增创建序号，解决同秒创建演示／普通课堂后重启默认选择不符创建顺序；保持最新创建规则，旧同秒记录按既有 ID 回退，不批量改写数据。
- 暂停中的术语任务重启后仍可通过显式恢复继续，保持原课堂归属；中断时 pending／running 的任务仍需单独重试，不自动重发。
- 修正原文后，已标记过期的问答不再进入新问题的历史上下文；旧答案、机器原稿及既有重试快照保留。

本次只修复问题，不包含课件识别、复习卡片或其他新功能。验证环境、真实／模拟范围与剩余限制见 [VALIDATION](VALIDATION.md)，升级和回退见 [README](../README.md)。

## v1.1.0 · 2026-10-24

- 网页 AI 设置：选择本地 Codex 或 OpenAI 兼容 Chat Completions API；编辑地址、密钥、模型并测试连接。
- API 覆盖意群解释、课堂问答与术语生成；语音仍本地转写。
- API 解释和回答逐步显示；未完成草稿与校验通过的正式结果分开保存。
- 可选 Windows DPAPI 加密记住密钥，支持仅本次使用、清除及更换地址时重新输入；不导出密钥。
- 进入 API 模式默认关闭逐段自动解释，显示课堂请求次数与可获取的 token 用量。
- 接入切换等待在途请求结束，积压任务由用户恢复，不自动换服务商或重试收费请求。
- 新结果保留接入、模型、用量信息；升级兼容旧课堂数据，启动器和健康接口增加版本识别。

真实第三方 API 的服务商、模型与计费行为需用户在网页完成实际连接验证；发布前使用合成服务验证功能，不宣称所有兼容接口均可用。
